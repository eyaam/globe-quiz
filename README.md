# 🌍 Globe Quiz

A flashcard game to learn the countries of the world. Each card shows a flag: guess the **country**, its **capital** and its **language(s)**.

- 194 countries
- Solo or 2 players on the same device, taking turns
- Scoring: 1 point for the country, 1 for the capital, 1 for a language, +1 bonus if all three are right
- Typo-tolerant: ignores accents and capitals, accepts common aliases (USA, Ivory Coast…)

## Play

Open `index.html` in a browser. No install or build needed.

To host it for free: **Settings → Pages**, pick the `main` branch and `/ (root)`, then save.
